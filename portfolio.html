Đồ án nhóm · HTML, CSS, JavaScript

CHỢ CŨ – Website mua bán đồ cũ

Giới thiệu: Phát triển nền tảng thương mại điện tử mua bán đồ cũ, kết nối người mua và người bán trực tuyến.

Nhiệm vụ trọng tâm: Xây dựng hệ thống điều hướng giao diện, tối ưu hóa luồng tương tác DOM phức tạp cho trang quản lý sản phẩm cá nhân, biểu mẫu đăng bán sản phẩm và các module thông báo thời gian thực.

Kết quả đạt được: Giải quyết bài toán đồng bộ hóa trạng thái giao diện phía client, kiểm soát xung đột CSS và tích hợp hiệu quả code giữa các thành viên trong nhóm.

Đồ án cơ sở dữ liệu · SQL Server

QUẢN LÝ GIẢI BÓNG ĐÁ

Giới thiệu: Xây dựng hệ thống cơ sở dữ liệu quan hệ quản lý toàn diện lịch thi đấu, bảng xếp hạng và thông tin đội bóng.

Nhiệm vụ trọng tâm: Phân tích mô hình thực thể kết hợp (ERD), thiết kế tối ưu các ràng buộc toàn vẹn phức tạp, khóa ngoại đa tầng và viết các câu lệnh truy vấn SQL nâng cao (Stored Procedures, Triggers) để xử lý tự động bảng xếp hạng và thẻ phạt.

Kết quả đạt được: Đảm bảo cơ sở dữ liệu hoạt động ổn định, loại bỏ dư thừa dữ liệu và giải quyết chính xác các bài toán ràng buộc nghiệp vụ thể thao khắc nghiệt.

Đồ án cá nhân · HTML, CSS, JavaScript

WEB HỌC TIẾNG ANH – Website học tập

Giới thiệu: Xây dựng ứng dụng web hỗ trợ người dùng học từ vựng trực quan và theo dõi tiến độ luyện tập hằng ngày.

Nhiệm vụ trọng tâm: Thiết kế kiến trúc giao diện responsive hoàn toàn từ đầu, lập trình logic xử lý tính năng tra cứu từ vựng thông minh và hệ thống lưu trữ trạng thái học tập cá nhân bằng JavaScript.

Kết quả đạt được: Nâng cao năng lực tự thiết kế và hoàn thiện một sản phẩm phần mềm chuẩn chỉnh từ ý tưởng ban đầu đến mã nguồn thực tế.
